# Font Files for Ingrid Bergman Interiors

This directory should contain the following font files:

1. abadi-extra-light.woff2
2. abadi-extra-light.woff
3. roboto-light.woff2
4. roboto-light.woff

Due to copyright restrictions, these font files are not included in the repository. You should acquire these fonts through appropriate licensing and place them in this directory.

## Recommended Alternatives

If you don't have these exact fonts, you can use the following alternatives:

1. For Abadi Extra Light:
   - Use any light sans-serif font
   - Modify the CSS to use a system font stack

2. For Roboto Light:
   - Use Google Fonts CDN (already included in the HTML)
   - Download from Google Fonts if you need a local copy

## Updating the CSS

If you decide to use alternative fonts, update the font-family declarations in the CSS files.
